# PokéAPI — Studies

Projeto desenvolvido para estudos de consumo de APIs utilizando **HTML, CSS e JavaScript**.

O projeto utiliza a [PokéAPI](https://pokeapi.co/) para buscar informações sobre Pokémon e possui duas aplicações:

- **Pokédex** — pesquisa informações de um Pokémon.
- **Mini Battle** — sorteia dois Pokémon e realiza uma batalha simples entre eles.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- JSON
- PokéAPI
